# Industrial Nexus

Create a modern, premium B2B industrial e-commerce website inspired by the attached reference website.

IMPORTANT:

Use the attached website only as a visual and structural reference.

Do NOT copy its HTML, CSS, JavaScript, source code, branding, text, logos, or proprietary assets.

Recreate the overall design language, layout patterns, spacing, navigation style, product presentation, and user experience with an original modern implementation.

The website should feel like a professional global manufacturer + e-commerce catalog.

Make the design significantly more modern, clean, responsive, and polished than the old reference.

Overall Design

Create a professional industrial technology website with:

Clean white/light background

Dark navy/charcoal typography

One strong accent color for buttons, links, highlights, and interactive elements

Large high-quality product imagery

Generous whitespace

Subtle borders and shadows

Rounded corners where appropriate

Modern typography

Smooth hover animations

Premium B2B/e-commerce appearance

Fully responsive design for desktop, tablet, and mobile

Avoid:

Overly colorful UI

Excessive gradients

Heavy glassmorphism

Huge rounded cards everywhere

Generic SaaS dashboard styling

Cartoon-style illustrations

Excessive animations
